Alur kerja

  1. Guru mengisi Template_Kisi_Kisi.docx → unggah di Langkah 1 → simpan → unduh Template Soal (sudah terisi nomor, bentuk, indikator, level untuk setiap varian).
  2. Guru mengisi Template Soal (stimulus, pertanyaan, pilihan, kunci, pembahasan) → unggah di Langkah 2 → periksa galat/peringatan & pratinjau → Terbitkan. Soal yang menyimpang dari kisi-kisi ditolak.
  3. Bagikan tautan/QR yang muncul ke siswa. Tautan berbentuk index.html?ujian=KODE.
  4. Rekap dan analisis: buka index.html → "Masuk sebagai guru" → pilih ujian. Saklar pembahasan ada di Daftar paket dan di dasbor guru.
  5. Revisi soal: perbaiki Word, unggah ulang dengan kode ujian yang sama → paket lama ditimpa (hasil siswa tetap tersimpan).

Kode ujian

Huruf besar/angka/strip, 3–31 karakter, unik per paket. Saran: MAPEL-MATERI-NOMOR, mis. KIM-STO-01, BIN-TKA-02.

Keamanan

Kunci jawaban tersimpan di server dan tidak pernah dikirim ke HP siswa; penilaian dilakukan di server. PIN diverifikasi di server (tabel tka_privat).
