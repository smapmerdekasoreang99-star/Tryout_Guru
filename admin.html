Data siswa

Menambah, mengubah, menonaktifkan, dan menghapus siswa hanya bisa dengan PIN operator/kurikulum. Dengan PIN ini Anda hanya dapat melihat daftar.

Alur kerja

  1. Guru mengisi Template_Kisi_Kisi.docx → unggah di Langkah 1 → simpan → unduh Template Soal (sudah terisi nomor, bentuk, indikator, level untuk setiap varian).
  2. Guru mengisi Template Soal (perintah soal, pertanyaan, pilihan, kunci, pembahasan) → unggah di Langkah 2 → periksa galat/peringatan & pratinjau → Terbitkan. Soal yang menyimpang dari kisi-kisi ditolak.
  3. Bagikan tautan/QR yang muncul ke siswa. Tautan berbentuk index.html?ujian=KODE.
  4. Rekap dan analisis: buka index.html → "Guru / pengawas" (atau tautan index.html?guru) → PIN → Menu guru: Daftar siswa (bantu login), Dasbor hasil, Uji coba soal, Halaman admin. Saklar pembahasan ada di Daftar paket dan di dasbor guru.
  5. Revisi soal: perbaiki Word, unggah ulang dengan kode ujian yang sama → paket lama ditimpa (hasil siswa tetap tersimpan).

Pengaturan server (config.js)

Agar tidak perlu mengedit baris ke-2 setiap kali ada pembaruan, buat sekali berkas config.js di folder yang sama dengan index.html (di GitHub: Add file → Create new file) berisi satu baris:
window.TKA_SUPABASE = { url: "https://xxxx.supabase.co", key: "eyJ..." };
Nilai url = Project URL dan key = kunci anon public (Supabase → Project Settings → API). Setelah itu index.html/admin.html versi baru cukup ditimpa apa adanya. Urutan prioritas: tautan ?sb=…&key=… > config.js > baris ke-2.

Kode ujian

Huruf besar/angka/strip, 3–31 karakter, unik per paket. Saran: MAPEL-MATERI-NOMOR, mis. KIM-STO-01, BIN-TKA-02.

Tiga PIN: operator, guru, pengawas

PIN operator/kurikulum (bawaan operator2026, kunci pin_operator): akses penuh, satu-satunya yang boleh menambah, mengubah, menonaktifkan, menghapus data siswa. PIN guru (bawaan merdeka2026, kunci pin): terbit paket, peruntukan, pengaturan, dasbor, reset hasil; data siswa hanya lihat. PIN pengawas (bawaan pengawas2026, kunci pin_pengawas): hanya lihat — dasbor tanpa tombol pengaturan, daftar siswa (NISN & tanggal lahir untuk membantu siswa yang lupa NISN), uji coba soal. Pembatasan dicek di server, bukan hanya disembunyikan. Ganti di SQL Editor: update public.tka_privat set v='PIN_BARU' where k='pin_operator'; (juga k='pin', k='pin_pengawas').

Peruntukan ujian (siapa yang boleh mengerjakan)

Saat menerbitkan (Langkah 2 atau jalur darurat) pilih Semua siswa, Kelas tertentu (klik rombel; tombol Semua kelas 12 memilih seluruh rombel tingkat itu), atau Siswa tertentu (centang nama, atau tempel daftar NISN). Siswa di luar peruntukan ditolak saat masuk dengan pesan yang jelas, dan tab Belum mengerjakan di dasbor hanya menghitung peserta. Peruntukan bisa diubah kapan saja: Daftar paket → ubah, atau dari dasbor guru (Peruntukan ujian → Ubah). Contoh: TO-MAT-TKA → semua kelas 12; TO-MAT-CHANDRA-1 → XII-1 dan XII-2; TO-OSN-INF-1 → 12 siswa peserta olimpiade.

Jalur darurat

Tab Jalur darurat menerbitkan paket langsung dari file soal (Template_Soal_Darurat.docx) tanpa Langkah 1, hanya dengan PIN darurat (bawaan darurat2026; ganti di SQL Editor: update public.tka_privat set v='...' where k='pin_darurat';). Kisi-kisi disusun otomatis dari soal dan ditandai Darurat. Untuk mengesahkan: Daftar paket → Unduh kisi-kisi → periksa/lengkapi di Word → unggah di Langkah 1 dengan kode yang sama; bila jumlah soal dan bentuk per nomor cocok, tanda Darurat dicabut (jejak "disahkan" tetap tercatat).

Data siswa & identitas

Tab Data siswa: unggah ekspor Dapodik/CSV. Setelah ada data siswa, siswa masuk dengan NISN + tanggal lahir (nama/kelas otomatis, satu hasil per ujian; guru bisa reset di dasbor). Per ujian, guru dapat membuka jalur tamu untuk siswa yang belum terdaftar dan menetapkan kode akses yang diumumkan di kelas.

Keamanan

Kunci jawaban tersimpan di server dan tidak pernah dikirim ke HP siswa; penilaian dilakukan di server. PIN diverifikasi di server (tabel tka_privat).
